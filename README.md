# Titanic AI Challenge — Live Prediction App

تطبيق Streamlit للاستخدام بآخر الورشة (سلايد ١٠: "خلينا نتنبأ براكب!").
مبني على نفس الألوان والستايل تبع عرض العرض التقديمي (Titanic_AI_Workshop.pptx).

## شو جوا المجلد

| File | الوظيفة |
|---|---|
| `titanic.csv` | الداتا الأصلية (٨٩١ راكب) |
| `train_model.py` | يدرّب موديل Random Forest ويحفظه بملف `titanic_model.pkl` |
| `titanic_model.pkl` | الموديل الجاهز (مدرّب مسبقًا — مو لازم تدرّبه من جديد) |
| `app.py` | تطبيق الويب (Streamlit) نفسه |
| `requirements.txt` | المكتبات المطلوبة |

## طريقة التشغيل (قبل الورشة)

```bash
pip install -r requirements.txt
streamlit run app.py
```

رح يفتح المتصفح تلقائيًا على `http://localhost:8501`. جربه قبل الورشة بيوم على الأقل، وتأكد إنه شغال على نفس اللابتوب اللي رح تستخدمه بالعرض.

إذا بدك تعيد تدريب الموديل (مثلاً بعد ما تعدّل الداتا)، شغّل أول:

```bash
python train_model.py
```

وهاد رح يحدّث `titanic_model.pkl`.

## كيف تستخدمه بالورشة (سلايد ١٠)

1. افتح التطبيق على الشاشة بشاشة كاملة (F11 لإخفاء شريط المتصفح).
2. فوق يمين الصفحة في ٤ أزرار سريعة تحمّل **نفس الركاب الأربعة اللي استخدمتهم بالافتتاحية** (٢٢ سنة درجة ثالثة، البنت الصغيرة درجة أولى، السيدة لحالها درجة ثانية، الرجل ٦٠ سنة درجة أولى) — اضغط عليهم واحد وحدة وقارن مع تصويت الحضور بالبداية.
3. بعدين اطلب من متطوع/متطوعة من الجمهور يخترعوا راكب جديد (عمر، درجة، جندر، أجرة...) وعبّي البيانات بنفسك على المسرح بينما هم يملوا عليك.
4. اضغط "PREDICT SURVIVAL" — النتيجة بتطلع فورًا مع نسبة الثقة، ومخطط "شو أثّر على القرار" (Feature Importance) تحت.
5. اربط بالخط اللي حكيته بالسلايد نفسه: "هاد نفس المنطق اللي استخدمتوه إنتوا بالتصويت، بس هلأ بالأرقام."

## ملاحظات

- دقة الموديل الحالي: حوالي **٨٢٪** (test accuracy) — رقم واقعي ومناسب تعرضه للجمهور، لأنه يفتح نقاش "ليش مش ١٠٠٪؟" وهاد بالضبط اللي بدك تشرحه (الاحتمالات مش يقين).
- التطبيق ما فيه أي كود ظاهر للحضور — بس فورم بسيط وزرار، بما يتماشى مع فكرة "بدون كود" تبعت الورشة.
- إذا الإنترنت بالمكان مش مضمون، شغّل التطبيق محليًا قبل ما توصل — ما بيحتاج إنترنت بعد أول تشغيل.
